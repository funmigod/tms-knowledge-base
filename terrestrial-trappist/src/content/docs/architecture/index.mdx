### Overview

This section helps you understand how Team Minipod’s transportation-management system (TMS) layer works: where a shipment enters the platform, which services own each part of the journey, and how information moves between them.

Use these pages to build a shared picture of the system before investigating a specific service or workflow. They describe the important domain boundaries, integrations, and architectural decisions that shape how we move orders from fulfillment through delivery.
