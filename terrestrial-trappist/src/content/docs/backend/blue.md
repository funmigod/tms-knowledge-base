## What is Blue?

Blue is GoBolt's Transportation Appointments Service. It is a backend API responsible for managing appointments across GoBolt's transportation and delivery operations.

The service supports appointment-related workflows by providing APIs for appointment data, scheduling, and operational coordination. It helps downstream transportation systems create, retrieve, and manage appointment information used during delivery planning and execution.

Blue is part of the Minipod transportation platform and supports appointment management as a core capability for coordinating delivery operations.

## Development notes

The service is built with TypeScript and runs locally through Docker Compose. It includes unit, end-to-end, and coverage test commands for validating API behavior.
